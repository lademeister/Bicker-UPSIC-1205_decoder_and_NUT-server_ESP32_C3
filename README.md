# Bicker-UPSIC-1205_decoder_and_NUT-server_ESP32_C3
Reverse engineering of Bicker UPSIC supercap-USV. Creates a NUT-Server to read it out over WiFi and use it liek a normal USV. Decode its internal data and status like charge percentage, current etc. Add a 128x32 OLED Display with status ans remaining time and add a programmable LED strip to show charge percentage.
